# PROJECT BRIEF

## Project

Self-Employed Payments

MVP-платформа для самозанятых, объединяющая:

- прием оплат по ссылке;
- автоматическое резервирование налога;
- монетизацию платформы;
- выпуск чеков;
- управление услугами;
- онлайн-запись клиентов;
- управление календарем;
- будущую интеграцию с номинальным счетом банка.

---

# Цель проекта

Создать SaaS-платформу для самозанятых, которая позволяет полностью вести деятельность в одном месте.

Пользователь должен иметь возможность:

- создать услугу;
- принимать оплату;
- принимать онлайн-записи;
- автоматически учитывать налог;
- автоматически выпускать чеки;
- получать выплаты;
- оплачивать тариф платформы.

## Монетизация платформы

Поддерживаются три модели.

### Процент

Комиссия удерживается из каждого клиентского платежа.

Платеж проходит через номинальный счет.

---

### Подписка

Самозанятый оплачивает фиксированный ежемесячный тариф.

Платеж поступает сразу на расчетный счет платформы.

---

### Гибрид

Фиксированная подписка плюс процент.

---

# Главный архитектурный принцип

Клиент

↓

Номинальный счет

↓

Налог

↓

Комиссия платформы

↓

Баланс самозанятого

---

## Деньги платформы

Самозанятый

↓

Расчетный счет платформы

# Универсальная модель

Любая коммерческая активность строится вокруг сущности CatalogItem.

CatalogItem используется:

- платежной ссылкой;
- календарем;
- онлайн-записью;
- аналитикой;
- будущим каталогом услуг.
