# Self-Employed Payments

Сервис для самозанятых, который автоматизирует:
- приём платежей
- расчёт налогов
- формирование чеков
- вывод средств

## Основная идея

Пользователь получает деньги → сервис:
- определяет доход
- резервирует налог
- формирует чек
- показывает доступный баланс

## Архитектура

- Web App (Next.js, mobile-first)
- Admin Panel (Next.js)
- Backend API (NestJS)
- Database (PostgreSQL)
- Queue (Redis)

## Основные сущности

- User
- PaymentLink
- IncomingPayment
- LedgerTransaction
- Receipt
- Payout

## Поток денег

1. Пользователь создаёт ссылку
2. Клиент платит
3. Деньги поступают на номинальный счёт
4. Сервис:
   - рассчитывает налог
   - резервирует часть средств
5. Остаток доступен пользователю
6. Пользователь выводит деньги
